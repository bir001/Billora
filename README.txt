BILLORA — BILLING APP DEMO

Included:
- Mobile-first billing dashboard using the supplied Nanu Cart design system (Royal, Midnight, Ocean, Indigo themes).
- Create invoices with multiple items, tax and discount.
- Customer directory and products/services catalogue.
- Invoice status tracking (paid/unpaid), invoice preview, print/save as PDF, share summary.
- Reports, business profile settings, JSON backup export/import.
- Browser localStorage persistence.

HOW TO RUN
1. Keep index.html, style.css and app.js in the same folder.
2. Open index.html in a browser, or upload the folder contents to a GitHub repository and enable GitHub Pages.

IMPORTANT DEMO LIMITATIONS
- This is a front-end prototype. Data is stored only in the current browser/device.
- No login, cloud database, multi-device sync, GST e-invoice/e-way bill, payment gateway, or automatic tax/legal compliance is implemented.
- Do not use it as a production accounting system until backend, authentication, database security, backups and applicable tax workflows are added and tested.
